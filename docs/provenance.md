# 来源与提取边界

本项目从作者已有个人创作工作区提取，固定来源修订 `96dc0cf13cea49606ff94c7843cde68c854175c1`。`SOURCE_MANIFEST.json` 记录源文件路径、来源内容 SHA-256 和当前导出内容 SHA-256。源路径仅用于核对来源，不是运行时依赖。

保留的部分：React 生图交互、FastAPI 对话和图片接口、JWT/邀请码登录、SQLite 用户与任务模型、任务幂等和恢复、原图下载与连续修改，以及可选通用语音链路。

独立化修改：删除工作台身份交换、非生图路由及无关数据库模型；改为显式环境配置；删除私有转发 header 依赖；提供独立登录页、启动入口和安装文件。默认图片协议与官方环境示例一致，原 OhMyGPT 协议保留为显式可选配置。默认使用本地原图，新参考图上传仍需 COS。

参考案例库使用已公开的 image-mcp 原创文字案例，重新映射稳定案例 ID；没有复制私有图片、生产 URL 或真实用户数据。前端无图片预览的案例显示文字说明。

导出不包含源仓 Git 历史、私人实例、运行配置、数据库、用户文件、密钥、宿主机词库或部署地址。没有改动原个人实例。第三方依赖遵循各自许可证；本仓代码使用 MIT。
